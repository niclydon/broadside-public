This repository is a sanitized public showcase derived from a private working
system.

What changed for the public edition:

- Personal names, hostnames, domains, filesystem paths, and operator-specific
  deployment notes were removed or generalized.
- Private workspace adapters, planning notes, memory artifacts, and operational
  scripts were excluded.
- Demo defaults and example brands replace private production identities.
- The repo is intended for architecture review and code reading first, not
  production deployment.

If you want to publish a real fork, treat this repo as a starting point and
replace the demo brands, credentials, storage, and publishing integrations with
your own.
